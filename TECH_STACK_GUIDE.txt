# 项目技术栈速查表
# 大语言模型快速理解项目的技术要点

## 核心技术组合
- **桌面框架**: Electron 29.4.6
- **前端框架**: Vue 3.4.21 + TypeScript 5.8.3
- **构建工具**: Vite 5.4.19
- **UI 库**: Naive UI 2.42.0
- **样式**: UnoCSS 66.3.2
- **状态管理**: Pinia 3.0.3
- **后端**: Python 3.13 + FastAPI + uvicorn
- **包管理**: uv 0.5.11 (Python)

## 关键架构决策

### Python 集成方式 (重要)
❌ 旧方案: PyFuze 编译 → 静态可执行文件
✅ 新方案: uv 运行时 → 动态虚拟环境管理

优势:
- 更灵活的依赖管理
- 更好的跨平台兼容性
- 更小的打包体积
- 更容易调试和维护

### 文件结构核心
```
electron-vue-lite/
├── src/                     # Vue 渲染进程
├── electron/main/           # Electron 主进程
├── electron/preload/        # 安全 IPC 桥接
├── python-project/ele-py/   # FastAPI 后端
├── assets/uv/              # uv 可执行文件
└── scripts/                # 构建脚本
```

## 开发时必知的关键文件

### 主要服务管理
1. `electron/main/services/uvPythonService.ts` - Python 服务管理器
2. `electron/main/handlers/pythonServiceHandler.ts` - IPC 处理
3. `electron/preload/bridges/pythonService.ts` - 前端 API

### 核心配置
1. `package.json` - 项目配置和脚本
2. `electron-builder.json5` - 打包配置
3. `python-project/ele-py/pyproject.toml` - Python 依赖

### 入口文件
1. `src/main.ts` - Vue 应用入口
2. `electron/main/index.ts` - Electron 主进程
3. `python-project/ele-py/main.py` - Python 服务

## 开发工作流

### 首次设置
```bash
npm run setup  # 下载 uv + 安装依赖
```

### 日常开发
```bash
npm run dev    # 启动开发环境 (自动管理 Python)
```

### 构建发布
```bash
npm run build  # 完整构建 + 打包
```

## IPC 通信模式
渲染进程 ↔ 预加载脚本 ↔ 主进程 ↔ Python 服务

API 暴露模式:
```typescript
// 预加载脚本暴露到 window 对象
window.pythonServiceApi.start()
window.appApi.getVersion()
window.windowApi.minimize()
```

## Python 服务特点
- **端口**: 8000
- **协议**: HTTP + WebSocket
- **管理**: 自动启动/停止/重启
- **环境**: 独立虚拟环境 (.venv)
- **依赖**: 通过 uv sync 自动安装

## 常见问题解决
1. **进程残留**: 已实现 Windows 进程树清理
2. **端口占用**: 自动检测和清理
3. **环境问题**: 支持虚拟环境重建
4. **跨平台**: uv 支持 Windows/macOS/Linux

## 安全考虑
- 预加载脚本限制 API 暴露
- IPC 通信验证和错误处理
- Python 服务仅本地访问
- 无 nodeIntegration 在渲染进程

## 性能优化点
- Vue 组件懒加载
- Electron 进程隔离
- Python 服务按需启动
- 构建时代码分割
